## Description
Crack Font tilts every letter of a text layer by a random angle, live on the canvas.

• Drag the fan or type how far letters may tilt left and right, up to 45° each way.
• Shuffle for a new random pattern until it looks right.
• Restore turns the letters back into one text layer, exactly as it was: kerning, styles, all of it.
• Works on the page, in frames, groups and auto layout. In auto layout nothing else moves.
• Undo works step by step. Select a cracked group later to keep editing.

How to use
1. Select a single-line text layer.
2. Open Crack Font and drag the fan.
3. Shuffle until you like it, then click Done.

Good to know
• Up to 200 characters, Latin letters and digits.
• Text inside instances can't be split; detach it or edit the main component.
• No network access, nothing leaves your file.

## What's new in 3.0
Live editing on the canvas, separate left/right angles with the new fan, Restore, support for frames and auto layout, and a fresh UI in Figma's own style. Groups made with earlier versions still work.
